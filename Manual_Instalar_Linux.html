1. Que es Linux

Linux es un sistema operativo gratuito y de codigo abierto, similar a Windows pero sin costo. Es usado en servidores, supercomputadoras, dispositivos moviles y PC de escritorio. Es mas seguro, rapido y personalizable que Windows.

Ventajas de Linux: Gratuito, seguro, rapido, no se vuelve lento con el tiempo, no necesita antivirus, y funciona en computadoras viejas.

2. Distribuciones populares

Distribucion Uso principal Nivel
Ubuntu Escritorio, servidores Principiante
Linux Mint Escritorio (parecido a Windows) Principiante
Fedora Desarrollo, servidores Intermedio
Debian Servidores, estabilidad Intermedio
CentOS Servidores empresariales Avanzado
Kali Linux Seguridad informatica Avanzado
Para principiantes: Te recomiendo Ubuntu o Linux Mint. Son los mas faciles de usar y tienen mucha documentacion en espanol.

3. Crear USB booteable

Paso 1: Descarga la ISO de la distribucion que elegiste desde su pagina oficial:
- Ubuntu: https://ubuntu.com/download/desktop
- Linux Mint: https://linuxmint.com/download.php

Paso 2: Descarga Rufus desde https://rufus.ie (es gratis y portable).

Paso 3: Inserta un USB de al menos 4 GB.

Paso 4: Abre Rufus y selecciona tu USB en "Dispositivo".

Paso 5: Haz clic en "SELECCIONAR" y busca el archivo ISO que descargaste.

Paso 6: Deja las opciones por defecto (esquema de particionado: MBR o GPT segun tu PC).

Paso 7: Haz clic en "INICIAR" y espera a que se cree el USB booteable.
IMPORTANTE: Todos los datos del USB se borraran. Asegurate de respaldar lo que tengas antes de continuar.

4. Configurar BIOS/UEFI

Paso 8: Reinicia la PC y entra al BIOS presionando Supr, F2 o F12.

Paso 9: Ve a la pestaña "Boot" o "Arranque".

Paso 10: Cambia el orden de arranque y coloca el USB como primera opcion.

Paso 11: Si tu PC es nueva, desactiva Secure Boot para poder instalar Linux.

Paso 12: Guarda los cambios y reinicia.

5. Instalar Linux

Paso 13: La PC arrancara desde el USB. Selecciona "Probar Linux" (Try Linux) para probarlo sin instalar, o "Instalar Linux" para instalarlo directamente.

Paso 14: Si elegiste instalar, selecciona el idioma y haz clic en "Continuar".

Paso 15: Selecciona "Borrar disco e instalar Linux" (instalacion limpia) o "Instalar junto a Windows" (dual boot).

Paso 16: Selecciona la zona horaria.

Paso 17: Crea tu cuenta de usuario: nombre, nombre de usuario y contraseña.

Paso 18: Haz clic en "Instalar" y espera a que se complete la instalacion (10-20 minutos).

Paso 19: Reinicia la PC y retira el USB cuando te lo indique.

6. Configuracion inicial

Paso 20: Al encender, veras el GRUB (menu de arranque). Selecciona Linux y presiona Enter.

Paso 21: Inicia sesion con tu contraseña.

Paso 22: Conectate a WiFi (icono de red arriba a la derecha).

Paso 23: Abre el "Centro de software" o "Synaptic" para instalar programas desde la tienda.

Paso 24: Actualiza el sistema ejecutando en la terminal: sudo apt update && sudo apt upgrade

7. Comandos basicos de terminal

Comando Funcion
sudo apt update Actualizar lista de paquetes
sudo apt upgrade Actualizar todos los paquetes
sudo apt install nombre Instalar un programa
sudo apt remove nombre Desinstalar un programa
ls Ver archivos de la carpeta actual
cd carpeta Cambiar de directorio
pwd Ver ruta actual
sudo reboot Reiniciar la PC
Tip: No tengas miedo de la terminal. Es como el "Simbolo del sistema" de Windows pero mucho mas poderosa. Con ella puedes hacer casi todo.
