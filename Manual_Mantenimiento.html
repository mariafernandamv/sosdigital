1. Que es el mantenimiento

El mantenimiento de PC es el conjunto de acciones preventivas y correctivas que se realizan para mantener la computadora en optimas condiciones de funcionamiento, prolongar su vida util y evitar problemas.

Tipo Descripcion Frecuencia
Preventivo Acciones para prevenir problemas (limpieza, actualizaciones) Cada 3-6 meses
Correctivo Reparar componentes o software que falla Cuando ocurre un problema
Predictivo Monitorear componentes para anticipar fallos Continuo

2. Herramientas necesarias

Herramienta Uso
Desarmadores (Phillips y plano) Abrir el gabinete y componentes
Aire comprimido Limpiar polvo de componentes
Brocha suave Limpiar polvo delicado
Pasta termica Cambiar pasta del procesador
Paño de microfibra Limpiar pantallas y superficies
Alcohol isopropilico Limpiar contactos y componentes
Pulsera antiestatica Evitar descargas electricas
USB booteable Reparar o reinstalar Windows

3. Mantenimiento preventivo (Fisico)

Limpieza externa

Paso 1: Apaga la PC y desconecta todos los cables.

Paso 2: Usa paño de microfibra humedecido para limpiar el gabinete, monitor y teclado.

Paso 3: Usa aire comprimido para limpiar entre las teclas.

Paso 4: Limpia el mouse con alcohol isopropilico.

Limpieza interna

Paso 5: Pon la pulsera antiestatica o toca una superficie metalica.

Paso 6: Abre el gabinete (desatornillar los tornillos laterales).

Paso 7: Usa aire comprimido para soplar el polvo de:
- Ventiladores (CPU, gabinete, tarjeta de video)
- Disipadores de calor
- Fuentes de poder
- Ranuras de expansion

Paso 8: Usa la brocha suave para componentes delicados.

Paso 9: Cierra el gabinete y reconecta los cables.
CUIDADO: NUNCA uses una aspiradora dentro del gabinete. La electricidad estatica puede danar los componentes. Usa aire comprimido o brocha.

4. Mantenimiento preventivo (Software)

Paso 10: Actualiza Windows: Configuracion > Windows Update > Buscar actualizaciones.

Paso 11: Actualiza los drivers (verificar fabricante).

Paso 12: Desinstala programas que no usas.

Paso 13: Limpia archivos temporales (cleanmgr).

Paso 14: Escanea con el antivirus.

Paso 15: Desfragmenta el disco HDD (NO SSD).

Paso 16: Crea un punto de restauracion del sistema.

5. Cambiar pasta termica

Paso 17: Apaga la PC y desconecta todos los cables.

Paso 18: Abre el gabinete y retira el ventilador del procesador.

Paso 19: Limpia la pasta vieja con alcohol isopropilico y un paño sin pelusa.

Paso 20: Aplica una cantidad pequena de pasta nueva (tamaño de un grano de arroz) en el centro del procesador.

Paso 21: Vuelve a colocar el ventilador y aprieta uniformemente.

Paso 22: Reconecta el ventilador a la tarjeta madre (conector CPU_FAN).

6. Cambiar componentes

Instalar memoria RAM

Paso 23: Apaga la PC y abre el gabinete.

Paso 24: Localiza las ranuras DIMM en la tarjeta madre.

Paso 25: Abre los seguros de la ranura.

Paso 26: Inserta el modulo RAM alineando la muesca.

Paso 27: Presiona firmemente hasta que los seguros cierren.

Instalar disco duro SSD

Paso 28: Localiza la bahia de discos en el gabinete.

Paso 29: Fija el SSD con tornillos o soporte adhesivo.

Paso 30: Conecta el cable SATA al SSD y a la tarjeta madre.

Paso 31: Conecta el cable de alimentacion SATA.

7. Monitoreo del estado

Herramienta Que monitorea
HWMonitor Temperaturas, voltajes, ventiladores
CrystalDiskInfo Salud del disco duro/SSD
MemTest86 Errores en la memoria RAM
FurMark Estres y temperatura de la GPU
Core Temp Temperatura del procesador

Temperaturas seguras

Componente Normal Peligro
Procesador 30°C - 70°C Mayor a 85°C
Tarjeta de video 30°C - 80°C Mayor a 95°C
Disco duro 25°C - 45°C Mayor a 55°C

8. Frecuencia de mantenimiento

Tarea Frecuencia
Limpiar polvo externo Cada semana
Limpiar polvo interno Cada 3 meses
Actualizar Windows Cada semana
Actualizar drivers Cada mes
Desfragmentar HDD Cada 3 meses
Cambiar pasta termica Cada 1-2 anos
Revisar temperaturas Cada mes
Backup de datos Cada semana
Recuerda: Un buen mantenimiento prolonga la vida de tu PC y evita problemas costosos. Es mejor prevenir que reparar.
