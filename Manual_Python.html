1. Que es Python

Python es un lenguaje de programacion de alto nivel, facil de aprender y muy versatil. Se usa para:

  • Desarrollo web (Django, Flask)
  • Ciencia de datos (Pandas, NumPy)
  • Inteligencia artificial (TensorFlow, PyTorch)
  • Automatizacion (scripts, bots)
  • Aplicaciones de escritorio
  • Videojuegos (Pygame)
Por que Python? Es el lenguaje mas recomendado para principiantes porque su sintaxis es clara y se parece al ingles. Tambien es uno de los mas demandados en el mercado laboral.

2. Instalar Python

Paso 1: Ve a https://www.python.org/downloads/

Paso 2: Haz clic en "Download Python 3.x.x" (la version mas reciente).

Paso 3: Ejecuta el instalador.

Paso 4: MARCA la casilla "Add Python to PATH" (MUY IMPORTANTE).

Paso 5: Haz clic en "Install Now".

Paso 6: Espera a que termine la instalacion.
IMPORTANTE: Si olvidas marcar "Add Python to PATH", no podras usar Python desde la terminal. Puedes reinstalarlo y marcar la casilla.

3. Verificar la instalacion

Paso 7: Abre la terminal (cmd o PowerShell).

Paso 8: Escribe: python --version

Paso 9: Presiona Enter. Deberia aparecer la version de Python instalada (ej: Python 3.12.0).

4. El interprete de Python

Python tiene dos formas de ejecutar codigo:

Modo Descripcion Como usarlo
Modo interactivo Ejecutas codigo linea por linea Escribe python en la terminal
Modo script Ejecutas un archivo completo python archivo.py
Prueba el modo interactivo:
python
>>> print("Hola, mundo!")
Hola, mundo!
>>> 2 + 2
4
>>> exit()

5. Tu primer programa

Crea un archivo llamado hola.py con el siguiente codigo:

# Mi primer programa en Python
print("Hola, mundo!")
print("Estoy aprendiendo Python")
print("2 + 2 =", 2 + 2)
Ejecutalo: Abre la terminal y escribe: python hola.py

6. Variables y tipos de datos

# Variables
nombre = "Juan"
edad = 17
estatura = 1.65
es_estudiante = True

# Mostrar variables
print("Nombre:", nombre)
print("Edad:", edad)
print("Estatura:", estatura)
print("Es estudiante:", es_estudiante)

# Tipo de dato
print(type(nombre))      # str
print(type(edad))        # int
print(type(estatura))    # float
print(type(es_estudiante)) # bool
Tipo Descripcion Ejemplo
str Cadena de texto "Hola"
int Numero entero 25
float Numero decimal 3.14
bool Verdadero o falso True / False

7. Operaciones basicas

# Aritmeticas
print(10 + 5)    # 15 (suma)
print(10 - 5)    # 5 (resta)
print(10 * 5)    # 50 (multiplicacion)
print(10 / 3)    # 3.333 (division)
print(10 // 3)   # 3 (division entera)
print(10 % 3)    # 1 (modulo/resto)
print(2 ** 3)    # 8 (potencia)

# Comparacion
print(5 > 3)     # True
print(5 == 5)    # True
print(5 != 3)    # True

9. Condicionales

# If / elif / else
edad = int(input("Cuantos anos tienes? "))

if edad >= 18:
    print("Eres mayor de edad")
elif edad >= 13:
    print("Eres adolescente")
else:
    print("Eres menor de edad")

10. Bucles

Bucle for

# Contar del 1 al 5
for i in range(1, 6):
    print(i)

# Recorrer una lista
frutas = ["manzana", "platano", "naranja"]
for fruta in frutas:
    print("Me gusta la", fruta)

Bucle while

# Contar mientras sea menor a 5
contador = 0
while contador < 5:
    print("Contador:", contador)
    contador += 1

11. Listas

# Crear una lista
numeros = [1, 2, 3, 4, 5]
nombres = ["Ana", "Luis", "Carlos"]

# Acceder a un elemento
print(numeros[0])    # 1 (primera posicion)
print(nombres[-1])   # Carlos (ultima posicion)

# Agregar elementos
numeros.append(6)
nombres.append("Maria")

# Eliminar elementos
numeros.remove(3)

# Longitud de la lista
print(len(numeros))  # 5

12. Funciones

# Definir una funcion
def saludar(nombre):
    print("Hola", nombre, "!")

# Llamar a la funcion
saludar("Juan")
saludar("Ana")

# Funcion con retorno
def sumar(a, b):
    return a + b

resultado = sumar(5, 3)
print("5 + 3 =", resultado)

13. Ejercicio practico

# Calculadora basica
print("=== CALCULADORA ===")
print("1. Sumar")
print("2. Restar")
print("3. Multiplicar")
print("4. Dividir")

opcion = input("Elige una operacion (1-4): ")
num1 = float(input("Primer numero: "))
num2 = float(input("Segundo numero: "))

if opcion == "1":
    print("Resultado:", num1 + num2)
elif opcion == "2":
    print("Resultado:", num1 - num2)
elif opcion == "3":
    print("Resultado:", num1 * num2)
elif opcion == "4":
    if num2 != 0:
        print("Resultado:", num1 / num2)
    else:
        print("Error: No se puede dividir por cero")
else:
    print("Opcion no valida")
