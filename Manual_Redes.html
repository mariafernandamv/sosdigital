1. Que es una red

Una red de computadoras es un conjunto de dispositivos (PCs, servidores, impresoras, etc.) conectados entre si para compartir recursos, datos y servicios.

2. Tipos de red por alcance

Tipo Siglas Alcance Ejemplo
Red Personal PAN 1-10 metros Bluetooth, auriculares inalambricos
Red de Area Local LAN Edificio o campus Red de la escuela, red de una oficina
Red de Area Metropolitana MAN Ciudad Red de una universidad con varios campus
Red de Area Amplia WAN Paises o continentes Internet

3. Tipos de red por conexion

Tipo Descripcion Velocidad
Red cableada (Ethernet) Usa cables UTP/STP para conectar dispositivos 100 Mbps a 10 Gbps
Red inalambrica (WiFi) Usa ondas de radio para transmitir datos 54 Mbps a 9.6 Gbps (WiFi 6)

4. Componentes de una red

Componente Funcion
Router Conecta la red local con internet y dirige el trafico
Switch Conecta varios dispositivos en la red local
Modem Convierte la senal del ISP a senal de red
Tarjeta de red Permite al dispositivo conectarse a la red
Cable UTP Conexion fisica entre dispositivos
Access Point Proporciona conexion WiFi

5. Direccion IP

La direccion IP es como la "direccion postal" de un dispositivo en la red. Identifica cada dispositivo unico.

IPv4

  • Formato: 192.168.1.100
  • 4 octetos separados por puntos
  • Cada octeto va de 0 a 255
  • Permite约4 mil millones de dispositivos

IPv6

  • Formato: 2001:0db8:85a3:0000:0000:8a2e:0370:7334
  • Usa hexadecimal
  • Permite约340 undecillones de dispositivos

Direcciones IP privadas

Rango Clase Uso comun
192.168.x.x C Redes domes y pequenas oficinas
10.x.x.x A Redes grandes empresas
172.16.x.x - 172.31.x.x B Redes medianas

6. Comandos de red

Windows

# Ver configuracion de red
ipconfig

# Ver configuracion detallada
ipconfig /all

# Ping a un servidor
ping google.com

# Ruta de red
tracert google.com

# Limpiar cache DNS
ipconfig /flushdns

# Ver conexiones activas
netstat -an

Linux/Mac

# Ver configuracion de red
ip addr show

# Ping a un servidor
ping google.com

# Ruta de red
traceroute google.com

# Ver conexiones activas
netstat -tuln

# Resolver DNS
nslookup google.com

8. Configurar una red basica

Paso 1: Conecta el cable Ethernet del router a la PC.

Paso 2: Ve a Configuracion > Red e Internet > Estado > Cambiar opciones de adaptador.

Paso 3: Haz clic derecho en "Ethernet" y selecciona "Propiedades".

Paso 4: Selecciona "Protocolo de Internet version 4 (TCP/IPv4)" y haz clic en "Propiedades".

Paso 5: Para configuracion automatica, selecciona "Obtener direccion IP automaticamente".

Paso 6: Para configuracion manual, ingresa la IP, mascara de subred y gateway.

9. Wifi: Configuracion y seguridad

Seguridad Nivel Descripcion
Sin contrasena Ninguno Cualquiera puede conectarse (NO recomendado)
WEP Bajo Seguridad antigua, facil de hackear
WPA Medio Mejor que WEP pero tambien vulnerable
WPA2 Alto Seguro y recomendado para la mayoria
WPA3 Muy alto La mas segura actualmente
Consejos de seguridad WiFi:
- Usa WPA2 o WPA3 como minimo.
- Cambia la contrasena por defecto del router.
- Cambia el nombre de red (SSID) por defecto.
- Desactiva WPS si no lo usas.
- Actualiza el firmware del router regularmente.

10. Problemas comunes de red

Problema Causa Solucion
No hay conexion a internet Cable suelto, router apagado, ISP con problemas Verificar conexiones, reiniciar router
Conexion lenta Muchas dispositivos, interferencia, router antiguo Desconectar dispositivos, cambiar canal WiFi
No obtiene IP DHCP desactivado, conflicto de IP Reiniciar adaptador de red, configurar IP manual
Se desconecta frecuentemente Señal debil, driver desactualizado Acercarse al router, actualizar driver de red
