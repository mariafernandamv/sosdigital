Limpieza

  1. Apaga la PC.
  2. Desconecta cables.
  3. Abre gabinete.
  4. Limpia polvo.
  5. Cierra todo.

Cambiar RAM

  1. Apaga PC.
  2. Abre gabinete.
  3. Quita RAM.
  4. Coloca nueva.
  5. Enciende.

Pasta termica

  1. Quita disipador.
  2. Limpia superficie.
  3. Aplica pasta termica.
  4. Coloca disipador.
  5. Verifica instalacion.

Disco duro

  1. Apaga PC.
  2. Instala disco.
  3. Conecta cables.
  4. Configura sistema.
  5. Listo.

Procesador

  1. Quita disipador.
  2. Cambia CPU.
  3. Aplica pasta termica.
  4. Monta todo.
  5. Enciende y verifica.
